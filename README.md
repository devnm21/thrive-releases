# Thrive releases

Public downloads and issue reports for [Thrive](https://app.getthrive.xyz). The source repository is private. This repository holds release builds and the forms the app uses when you report a problem.

## Mac alpha

The latest Apple silicon build is on the [releases](https://github.com/devnm21/thrive-releases/releases) page.

The app is unsigned. The first time you open it:

1. Move Thrive to Applications.
2. Right-click the app and choose Open.
3. Confirm Open in the dialog.

Windows is not in this alpha. The web app is at https://app.getthrive.xyz.

## Versions

Tags are `v0.1.0-alpha.N`. The file name is `Thrive-<version>-arm64.dmg`.

## Issues

- [Report an issue](https://github.com/devnm21/thrive-releases/issues/new?template=bug.yml) for the app or the website.
- [Report a problem](https://github.com/devnm21/thrive-releases/issues/new?template=problem.yml) when a practice problem, its tests, or its statement looks wrong.

Leave your solution code and transcript out of the report unless you want them public. This repository is public.
